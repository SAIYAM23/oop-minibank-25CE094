# MiniBank

A console-based banking application developed for the
CHARUSAT CEUE203 Object-Oriented Programming practicals.

## Requirements
- Java JDK 17 or newer

## Compile
javac MiniBank.java

## Run
java MiniBank

## Features implemented
### Practical 1
- BankInfo record
- MenuOption enum
- Menu-driven console interface
- Switch expressions
- Input validation
